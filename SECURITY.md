# Security Policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** form for this repository.
Do not open a public issue for a vulnerability before a fix is available.

Include the SimpleClipboard version, Ubuntu and GNOME Shell versions, clear
reproduction steps, and the security impact. Do not attach real clipboard
history, database files, screenshots containing secrets, tokens, or passwords.

SimpleClipboard stores clipboard history locally. If a report needs sample
data, reproduce it with synthetic content first.
